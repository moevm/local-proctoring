# Расширение: инструкция пользователю

Текущая версия — в [VERSION](../VERSION). Настройка сервера и обновление —
в [корневом README](../README.md), контракт API — в [API-COMPATIBILITY](API-COMPATIBILITY.md).
Нужен Google Chrome 134+; отдельный сервер из этого репозитория не используется.

## Установка

1. Получите актуальный каталог `client` у сопровождающего проекта.
2. Откройте `chrome://extensions`, включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите `client`.
4. Проверьте ID `nlhjjbgkbfkopkigkbkojpkbffbkeohg` и закрепите расширение в панели.
5. Войдите на сайт прокторинга в этом же профиле Chrome.

## Обновления

При открытии расширения над формой появляется результат проверки обновлений.
Если версия устарела, видны актуальный номер и ссылка на архив, если она задана.
Обновляйте расширение после завершения записи и выгрузки видео; сохраняйте его ID
и данные. Перед началом записи серверная политика проверяется ещё раз.

## Запись

1. Откройте расширение, заполните данные студента и сессии.
2. Нажмите «Разрешения» и предоставьте доступ к экрану, камере и микрофону.
3. Начните запись. Оставьте служебную вкладку открытой до окончания отправки.
4. Нажмите «Остановить» и дождитесь завершения сохранения.
5. Отправьте запись и дождитесь явного сообщения об успехе.
   При включённом локальном сохранении дождитесь также окончания скачиваний.

Микрофон записывается в видео камеры; без камеры — в видео экрана.
Закрытие popup не прерывает отправку. Закрытие служебной вкладки или Chrome может
потерять последний фрагмент записи.

## Ошибка отправки и восстановление

При ошибке оригиналы остаются в OPFS браузера. Повторная отправка сначала проверяет
серверный статус и не загружает уже сохранённую запись второй раз.
Если сервер сохранил видео, но не запустил ML, обратитесь к администратору.

«Мои записи» позволяет просмотреть и скачать оставшиеся файлы, включая файлы без
индекса. Скачивание из этого списка не удаляет оригинал.
Не удаляйте расширение, профиль и данные сайта, пока не выгружены все записи.

Для работы без сервера оператор заранее задаёт `server_connection=false` и
`local_video_saving=true`. Не переключайте режим во время записи.
Для ручной загрузки на сайт нужна одна пара WebM; несколько отдельных фрагментов
нельзя объединить переименованием или простым склеиванием файлов.
