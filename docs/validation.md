# Результаты проверок

| Проверка | Результат |
| --- | --- |
| Unit, Node 24 в контейнере без сети | 70/70 |
| HTTP-контракт mock API, тот же контейнер | 10/10 |
| Chrome UI, 74 сценария по два запуска | 148/148 |
| ESLint, Prettier, VERSION, git diff --check | Прошли |

Chrome UI выполнен на хосте с Xvfb, отдельными профилями, синтетическими
устройствами и mock HTTP. Матрица сохранения охватывает server_connection=false,
подключение без отправки видео, ошибки сервера/сети, скачивание обоих WebM,
отправку и восстановление после потери подтверждения. Проверены декодирование
локальных файлов, совпадение SHA-256 и сохранность оригиналов при отказах.

Проверены запись дольше 11 секунд, неожиданный stop рекордера и потеря устройств.
Причина жалобы на остановку в 11 секунд не воспроизведена.

Не проверены production HTTPS, реальные устройства студентов, многочасовая запись,
нагрузка на production. Полный автономный Compose-набор не запускался.
Команды: [tests/README.md](../tests/README.md).

## Настоящий локальный стенд

Проверены запушенные исходники расширения с локальным API-адресом: запись без
сети и локальное скачивание обоих WebM; запись со скачиванием и отправкой через
настоящий backend. OPFS очищен после подтверждения, SHA-256 скачанных и серверных
файлов совпадает. Обе ML-задачи завершены, результаты прочитаны из GridFS,
callbacks сохранены, оба потока воспроизводятся на teach с синхронизацией.
Для воспроизведения WebM без длительности применено проверенное исправление web.
