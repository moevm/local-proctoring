## CI

[tester.yml](../.github/workflows/tester.yml) собирает tests/Dockerfile и запускает
Compose-сервис tests на push / pull request и вручную. Все инструменты находятся
в образе; по умолчанию выполняются форматирование, ESLint, VERSION, unit,
HTTP contract и Playwright UI.
CI больше не поднимает неактивный server и не запускает исторические Python-тесты.
Артефакты: JSON, JUnit и HTML-отчёт Playwright, без профилей Chrome и видео.

## Что ещё требует отдельной проверки

- Настоящий backend / Mongo / ML / callbacks / teach проверяет отдельный
  [сквозной runner](https://github.com/OSLL/proctoring/blob/pre-release/tests/extension/README.md). Он не входит в этот
  контейнерный набор и в этом прогоне не запускался.
  Исторический прогон 23.10 отделён в validation.md.
- Windows, физические устройства и реальные системные диалоги разрешений,
  production HTTPS / cookie / origin. Ошибки устройств здесь вводятся на границе API;
  это не физическое отключение USB.
- Многочасовая запись, расход памяти, заполнение настоящего диска и большие WebM.
  Вызов четырёхчасового callback не является endurance-тестом.
- Все сочетания смены устройств между фрагментами; авария строго во время
  последнего OPFS write; нативный popup во всех состояниях и во время зависшего запроса.
- Конкурентный read-modify-write логов из разных extension-контекстов и освобождение
  всех Blob URL. Проверена очередь одного контекста; общей транзакции storage нет.
- Автоматическая установка релизного ZIP. VERSION / key проверяются в CI,
  упаковка и целостность ZIP — отдельно в release workflow.

При аварии браузера последний незафиксированный чанк может быть потерян.
Crash / reload тесты приостанавливают MediaRecorder, дожидаются реального OPFS close
и затем подтверждают сохранение зафиксированных байтов и индекса. Они не проверяют
восстановление неуспевших записаться данных.

Unit coverage исполняет 7 из 13 runtime-модулей: background, common, logger,
plugin-policy, upload, download и recorder-writer. DOM-модули index / media /
popup-policy / recordings / content / help проверяются в Chrome. Проценты V8 unit
не являются общим покрытием плагина; VM загружает неизменённые ESM-модули с отдельным состоянием и browser globals;
процессный globalThis не меняется. Тесты не ограничиваются проверкой наличия строк в исходнике.
