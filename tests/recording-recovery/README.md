# Восстановление записей

Из корня local-proctoring: `node tests/recording-recovery/chrome.cjs`.
Нужны `/usr/bin/google-chrome` и установленный Playwright соседнего
`../proctoring/tests/ui`. Используется отдельный профиль /tmp и случайный loopback-порт.
Рабочие профили, env и backend не используются. HTTP-сервер синтетический:
принимает multipart, сохраняет признак приёма и обрывает начатый JSON-ответ;
отдельные пути зависают до abort. OPFS и MediaRecorder настоящие.
Ошибки чтения, удаления и квоты вводятся на границе соответствующих Chrome API,
чтобы воспроизвести их без повреждения диска. Все файлы синтетические.
Артефакты и отчёт остаются в напечатанном /tmp-каталоге.
